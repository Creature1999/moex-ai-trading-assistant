# MOEX AI Trading Assistant — Web v2 (учебный прототип)

## Новое
- Каталог бумаг из MOEX ISS с постраничной загрузкой и выбором основных режимов торгов.
- Фоновое сканирование каталога с отображением прогресса; результаты сортируются по баллу и оценке оборота.
- Кнопка «Тест» для приблизительного исторического теста каждого инструмента: вход на следующем открытии, выход через 10 торговых дней, 0,1% комиссия + 0,1% проскальзывание на каждую сторону.
- Исходный сканер пяти тикеров и график сохранены.

## Установка на GitHub + Render
Загрузите в корень репозитория main.py, requirements.txt, render.yaml, README_RU.md и папку static с index.html. НЕ кладите index.html только в корень: сервер читает static/index.html. В Render выберите Manual Deploy → Deploy latest commit.

## Ограничения
- Список бумаг берётся из рынка shares MOEX ISS для выбранных режимов MARKET_BOARDS. Это не гарантия охвата всех возможных режимов/акций; могут попадать и инструменты, отличные от обыкновенных акций. Отсутствие истории, закрытие торгов, смена тикера и ошибки сети сокращают число проанализированных бумаг.
- Полное сканирование может занимать много минут; бесплатный Render может засыпать/перезапускаться, прерывая задачу. Запуск вручную; постоянный фон не гарантируется.
- Результаты живут в памяти процесса и исчезают при перезапуске. SQLite на free Render тоже не постоянная.
- Учебный бэктест не учитывает дивиденды, корпоративные действия, исполнение заявок, налоги, ограничения ликвидности и корректировку цен. 900 календарных дней истории могут ограничивать выборку. Винрейт не прогнозирует результат будущей торговли.
- RSS-заголовки — не AI-анализ; автоторговли нет. Сигналы не являются инвестиционной рекомендацией.
