# MOEX AI Trading Assistant — Web v1.0

Веб-приложение для анализа российских акций MOEX. Открывается по URL после публикации на хостинге. Не требует установки Python на пользовательский компьютер.

## Что реализовано
- Адаптивная веб-панель.
- Получение дневных свечей через MOEX ISS для списка тикеров.
- Расчёт EMA20/50/200, RSI14, ATR14, фильтр объёма.
- Эвристическая оценка 0–5 и кандидатный бычий сетап.
- Расчёт ориентировочных уровней от ATR.
- История сканирований в SQLite.
- Telegram-уведомления о кандидатных сетапах при автоматическом сканировании.
- Подключаемые RSS-ленты (заголовки отображаются; смысловой AI-анализ новостей ещё не реализован).

## Публикация на Render
1. Создайте аккаунт на Render.
2. Создайте новый GitHub-репозиторий и загрузите в него файлы проекта.
3. В Render выберите New → Blueprint, подключите репозиторий с `render.yaml`.
4. Render создаст веб-сервис. Для постоянного хранения SQLite нужна поддержка persistent disk на выбранном тарифе.
5. В Environment задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
6. После Deploy откройте выданный Render URL.

`render.yaml` использует платный Starter instance и диск. Перед подтверждением проверьте актуальную стоимость и доступность тарифов Render. Возможен иной хостинг с постоянным диском и поддержкой фонового процесса.

## Telegram
1. В Telegram откройте @BotFather и выполните `/newbot`.
2. Сохраните токен в секрете `TELEGRAM_BOT_TOKEN` в Render.
3. Напишите своему боту `/start`.
4. Получите chat_id через Telegram Bot API getUpdates (не публикуйте токен).
5. Сохраните chat_id в `TELEGRAM_CHAT_ID`.

## Автоматическое сканирование
В `SCAN_INTERVAL_MINUTES` укажите число минут, например `60`. Для корректной работы фонового цикла веб-сервис должен оставаться запущенным. Для production лучше вынести расписание в отдельный worker/cron job, чтобы не запускать несколько сканеров при масштабировании приложения.

## Источники и ограничения
- Котировки: MOEX ISS. Доступность истории, задержки, режимы торгов и ограничения зависят от инструмента и правил MOEX.
- По умолчанию используется режим TQBR. Не все инструменты и фонды обязаны торговаться в нём; при необходимости задайте соответствующий режим в `MOEX_BOARD`.
- Новости: RSS можно задать в `RSS_FEEDS`; список источников намеренно не предзаполнен, чтобы не выдавать неподтверждённые ленты за проверенные.
- Текущая оценка 0–5 — количество совпавших фильтров, не вероятность прибыльной сделки и не винрейт.
- Это прототип аналитики, не инвестиционная рекомендация. В нём нет полноценного бэктеста, AI-классификации новостей, расчёта комиссий/спреда, учёта дивидендных гэпов и корпоративных событий.
- Не подключайте автоторговлю и не используйте реальные деньги до проверки стратегии на истории и paper trading.
